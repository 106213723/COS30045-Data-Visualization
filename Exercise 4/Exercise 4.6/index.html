Exercise 4.6

Scaling the chart

Scales translate data values into screen positions, so the chart fits its drawing area no matter how big or small the numbers are.

What this step does

d3.scaleLinear() maps model counts from a domain of 0 to 1200 (a little above the largest count) onto a range of 0 to 400. The viewBox is now only 500 wide, so raw counts would run off the edge; the scale keeps every bar inside it and leaves 100 units free for labels in Exercise 4.7.

d3.scaleBand() maps each brand name to a vertical position and gives every bar the same thickness, with padding(0.2) leaving a gap between them. It replaces the old barHeight and barSpacing constants, which are commented out.

Key idea

Try changing the viewBox width or the scale's domain and range: the bars resize to fit. The chart still has no labels, so you cannot yet tell which bar is which; labels are added in Exercise 4.7.
