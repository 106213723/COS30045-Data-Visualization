Exercise 4.2

Selecting and changing elements with D3

Before drawing charts, D3 needs to find elements on the page. This step uses selections to restyle existing elements and add new ones.

What this step does

d3.select() returns the first element that matches a CSS selector, and d3.selectAll() returns every match. A selection can then be changed with .style(), .attr() and .text(), or extended with .append().

Everything below starts as plain HTML. The green page heading, the extra paragraph, the bold list and the green rectangle are all added by main.js, a separate file from the site's own script.js. Bare d3.select("div") and d3.select("svg") would pick the navigation bar and menu icon first, so those targets are given ids.

Key idea

Methods such as .style() and .append() return a selection, so they can be chained one after another in a single statement.
