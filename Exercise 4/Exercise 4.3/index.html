Exercise 4.3

Setting up D3 and a responsive SVG

D3 is added to the page with a single script tag. This step checks that it has loaded and creates the SVG that later charts will be drawn in.

What this step does

The D3 library is loaded from https://d3js.org/d3.v7.min.js before main.js, so the global d3 object is ready when our code runs.

D3 appends an <svg> to the .responsive-svg-container div. Instead of a fixed width and height it has a viewBox of 1200 by 1600, which defines its own coordinate system. The .responsive-svg-container class in style.css centres the container and lets it grow to 1200px, so the box changes size with the window. The black border shows the edge of the canvas.

Key idea

Shapes inside a viewBox are positioned in viewBox units, not screen pixels. Resize the browser window and the rectangle keeps the same proportions.
