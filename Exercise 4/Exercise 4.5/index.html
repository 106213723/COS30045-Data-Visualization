Exercise 4.5

Binding data and drawing with it

With the data loaded, D3 can create one shape for every row. This is the core idea behind every D3 chart.

What this step does

svg.selectAll("rect").data(data).join("rect") matches the data array to rectangles. There are no rectangles yet, so join creates 25 of them, one per brand, and each one remembers its row of data.

Each bar's width is set straight from its count, so Samsung's 1,090 models make a bar 1,090 units wide. Each bar also gets a class linked to its count, such as bar bar-1090, which you can see in the DOM. Every bar starts at x = 0, and the y position comes from its index in the sorted array: i * (barHeight + barSpacing).

Key idea

Using raw values as pixel sizes only works because the counts happen to fit the 1200-unit viewBox. A dataset with larger numbers would run off the edge, which is the problem scales solve in Exercise 4.6.
