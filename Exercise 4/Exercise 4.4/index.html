Exercise 4.4

Loading data from a CSV file

Charts are built from data, so the next step is to read a dataset into the browser and check that it arrived correctly.

What this step does

tvBrandCount.csv has one row per television brand and the number of models that brand has in the course TV dataset. It was made by counting models per brand and keeping the 25 brands with at least 20 models.

d3.csv() loads the file and passes each row through a function that turns count from text into a number. The data is logged to the console, summarised with d3.max, d3.min and d3.extent, then sorted from largest to smallest with d3.descending.

Key idea

d3.csv() is asynchronous: the rest of the code waits inside .then() until the file has loaded. Open the console (F12) to see the logged output.
