About the project

This is a student data-visualisation project about appliance energy consumption. It sets out to present energy data clearly enough that a reader can see how everyday technology choices affect what a household spends on electricity.

Methodology

Built for clarity

The site is built with plain web standards so the structure stays readable and the content loads quickly. There is no framework and no build step: every page is hand-written HTML with a single external stylesheet and a single external script.

  • Semantic HTML Landmarks, headings and lists that describe the content, so the pages work with assistive technology.
  • Modern CSS Custom properties, CSS grid and flexbox drive a consistent editorial layout across all three pages.
  • Interactive JavaScript Vanilla JavaScript powers the FAQ accordion, the navigation menu and the current year in the footer.
  • Data visualisation The Televisions page is laid out as a data story, ready for interactive charts to be added in later weeks.

About the data

Being open about where the numbers come from is part of the exercise. The notes below describe how the data will be sourced and handled.

Data source

The television dataset supplied with the unit will be used as the primary source. Its origin and collection date will be recorded here once the visualisations are built.

Data processing

Values will be checked for missing entries and converted to common units, such as kWh per year, so that models can be compared on the same basis.

Accuracy and limitations

Real consumption depends on settings, room brightness, content and the age of the appliance. Published figures come from standardised tests, so they indicate relative differences rather than a guaranteed bill.

Privacy

The site collects nothing. There are no analytics, no cookies and no accounts, and any interactive features run entirely in your browser.

Ethics

This is coursework, not a product review. No manufacturer sponsors it and no brand is being promoted. Charts will be scaled honestly, with axes starting at zero wherever truncating them could mislead.

AI declaration

Generative AI tools were used while building this site to help with code structure, syntax and debugging. All code was reviewed, tested and adapted before it was included. The full reflection is in the project README.

What comes next

In later weeks the Televisions page will be extended with interactive charts built using the D3.js library, replacing the placeholders that currently mark out each chapter of the data story.
